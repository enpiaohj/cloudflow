# CloudFlow v0.11.0

发布日期：2026-11-06

## 版本概述

本版新增规则端口 ±1 快捷调整，缓解虚拟机读取慢 / 卡住的问题（令牌缓存与规格信息后台补齐），并更换为立体风格的程序图标（深色 / 浅色两套）。属于向后兼容的新功能发布（MINOR）。没有独立 Build Number。

## Added

- 网络规则表「端口」列两侧新增 − / + 快捷按钮：把端口号减 1 / 加 1 并提交（例如 31001 → 31002 / 31000）。点击后先弹出「更改端口号」确认框，确认才提交，取消不改动；提交仍经 Operation Engine（`network.change_port`）的影响确认与审批，端口范围 1–65535，越界不提交。有待审批任务或上一次快捷提交未结束时再次点击被忽略。
- 规则编辑面板的输入框右侧新增上下箭头，用于把当前值加 1 / 减 1（端口 1–65535，优先级 100–4096）。只改输入框，不自动提交，仍需点「提交变更」。
- 立体风格新图标：深海军蓝圆角底盘 + 立体蓝色缎带字母 C（下端拖出流线）。程序、任务栏和窗口图标使用深色系；窗口内 Logo 随主题切换（深色主题用深色系，浅色主题用浅色系）。图标由 `tools/assets/generate_icon.py` 生成。
- 立体步进按钮样式（`Cf.StepperButton`）：浅色高光、细边框、微投影，悬停描边变主色，按下下沉。

## Changed / Improved

- 虚拟机清单读取更快、更稳：
  - 个人账户（嵌入式 Azure CLI）的访问令牌改为内存缓存，到期前 5 分钟视为过期，并发请求共用一次获取。此前每个 Azure 请求都会单独拉起一个 `az` 进程，页面并发请求时尤其慢。
  - 清单返回后，内存 / vCPU 的规格查询改为不同「订阅 + 区域」最多 4 路并行，并最多等待 4 秒；超时先显示列表，规格在后台补齐后两列自动刷新（此前列表要等规格查完才显示）。
- 提示文案按 Microsoft 中文风格统一：「更改端口号」「要将入站规则“xxx”的端口号从 A 更改为 B 吗？」「端口号必须介于 1 到 65535 之间」；确认框不再附带内部流程说明。

## Fixed

- 无独立缺陷修复。（开发过程中发现并已在发布前修复的两处自引入问题：规则编辑面板因按钮样式与控件类型不匹配而无法打开；浅色 Logo 资源未登记导致启动异常。均未进入已发布版本。）

## Known Issues / Limits

- 首次启动后的第一次读取仍需要拉起一次 `az` 取令牌，会比后续慢；网络 / 代理慢时读取仍受 Azure 请求超时（默认 300 秒，可在设置中调整）限制，本版没有改变该默认值。
- 清单刚显示时内存 / vCPU 两列可能先显示「—」，规格在后台补齐后自动刷新；规格查询失败时这两列保持「—」。
- Resource Graph 单次查询默认最多返回 1000 条，本版未增加分页。
- Windows 会缓存可执行文件图标：任务栏、开始菜单、桌面快捷方式在替换为新版后可能暂时仍显示旧图标，需重新固定 / 重新创建快捷方式或重启资源管理器。
- README / 用户手册截图沿用 v0.10.0 界面，未包含端口 ±1 按钮与新图标。
- 费用采用 ActualCost 分析，非发票；Azure Monitor 指标受规格支持与延迟影响；其余限制同 v0.10.0。
- 本版未进行代码签名；真实 Azure 环境端到端联调未执行。

## 安装与升级

- Windows 10 19041 或更新版本，x64。下载 `CloudFlow-v0.11.0-win-x64.exe` 或 `CloudFlow-v0.11.0-win-x64.zip`，ZIP 解压后运行同名 EXE；自包含 .NET 运行时。SSH 终端需要 WebView2 Runtime；个人账户 Azure CLI Runtime 按需下载。
- 退出旧版后启动新版，本地账户 / 设置 / 任务 / SSH 凭据保留；不需要清空本地数据，设置与数据格式无变更。
- 回退：退出新版，运行已归档的 v0.10.0 产物；不要删除或覆盖旧版本快照。新版与旧版共用同一份本地数据，格式兼容。
