# CloudFlow v0.10.0

发布日期：2026-10-12

## 版本概述

本版新增独立成本分析、NSG 优先级编辑和完整任务详情，统一列表、筛选器及侧边编辑面板，并修复优先级冲突、请求超时和列表误跳转。版本属于向后兼容的新功能发布（MINOR）。没有独立 Build Number。

## Added

- 左侧新增「成本分析」，首页「查看成本分析」跳转同一页面。支持本月、上月、近 7 / 30 天和自定义 UTC 日期范围；资源、资源组、订阅与关键字可组合筛选，显示 Scope 合计及筛选合计。
- 成本明细支持按资源或资源组汇总；按订阅与币种隔离同名组，保留负数、零金额及未关联资源的费用。完整资源 ID 可查看、复制；完整错误日志可展开、滚动、复制。
- NSG 规则支持编辑优先级，允许 100–4096 的整数，同方向冲突在校验与执行阶段拒绝；仅更改优先级，保留其他配置。
- 首页最近操作、任务中心与顶栏进行中任务共用只读详情，支持双击、Enter 和详情按钮，展示完整结果、错误、时间、资源 / 请求标识及本任务审计，运行中更新可见。
- 设置新增 Azure 请求超时，默认 300 秒，可选 60 / 120 / 180 / 300 / 600 / 900 秒；后续请求生效，进行中请求保留原超时。

## Changed / Improved

- 统一浅色 / 深色的卡片、表格、菜单、输入和筛选器；筛选器采用固定标签。标准 / 紧凑表格实时切换，保存失败恢复原值。网络规则表增加序号、优先级、源、目标，仅选中行加粗。
- 调整主窗口比例、页面间距和小窗口滚动；网络摘要与连接详情分层，入站 / 出站共用筛选与新建入口，规则编辑和影响确认使用主窗口右侧面板。
- 风险类审批默认关闭，支持「仅高危」及「所有写操作」，已有设置保留；删除与共享子网 NSG 的强制影响确认仍不可绕过。面板显示实际审批状态与执行进度，返回或关闭待审批面板取消本次任务。
- 首页虚拟机统计卡可按总数、运行中、已解除分配、需要关注跳转，清除旧筛选并保留 Scope；支持键盘访问。
- 详情页摘要 / 网络 / 磁盘 / 性能分别显示读取状态与更新时间，失败保留同一资源的旧数据；连续刷新取消前次读取，离开页面或上下文切换阻止迟到结果覆盖。
- 成本页切换 Scope / 账户自动重新读取，离开取消未完成查询，再次进入保留本次运行中的日期及汇总方式。资源组汇总在本地执行，无额外 Azure 请求。

## Fixed

- 新建 NSG 规则不再固定占用已有优先级；建议从 400 起按 10 递增，整十档占满时寻找其他可用整数。Azure 并发写入冲突仍如实反馈，可刷新后重试。
- 修复 Azure HTTP 固定 100 秒超时无法调整；统一 ARM 与相关 Azure 查询的超时配置。新增设置写盘失败时恢复原选项并显示错误，避免显示值与实际值不一致。
- 修复虚拟机单击立即进入属性页：单击选中，双击数据行或 Enter 进入详情；表头、空白区、复选框和菜单按钮不触发误跳转。
- 虚拟机、所有资源、资源组、网络规则和磁盘右键先选择实际目标，避免操作旧选中行；磁盘整行右键创建快照使用正确磁盘。
- 修复规则名称点击无响应及编辑 / 审批面板生命周期问题，避免重复提交或关闭执行中的操作；失败保留可编辑输入。
- 性能页读取真实 Azure Monitor 数据，区分缺失值与真实 0；微小非零值保留有效精度，磁盘字段完整参与可用性判断，显示采样范围。
- 成本分页失败不计入不完整订阅结果；部分失败如实显示，仅合计完整成功订阅，不以 0 或演示值替代失败。分页地址校验与 429 有界重试保留认证及取消边界。

## Known Issues / Limits

- 费用采用 ActualCost 分析，非发票或支付记录；服务数据可能延迟。部分订阅失败时合计只覆盖成功订阅；不同币种不换汇合并。
- Azure Monitor 指标受规格支持、采样窗口与延迟影响；磁盘百分比不是空间占用。
- 设置的超时是单次 HTTP 请求限制，不限制 SDK 重试 / 长操作总时长；SSH、交互登录、Runtime 下载及公网 IP 查询使用各自的超时。
- NSG 建议值可能在其他客户端并发写入后冲突，需刷新重新选择；不能依靠客户端分配消除服务端竞争。
- 历史审计记录若缺少 Job 关联，不会冒充当前任务审计。成本日期和汇总方式只保留于本次应用运行。
- 本版未进行代码签名；真实 Azure 环境端到端联调未执行。

## 安装与升级

- Windows 10 19041 或更新版本，x64。下载 `CloudFlow-v0.10.0-win-x64.exe` 或 `CloudFlow-v0.10.0-win-x64.zip`，ZIP 解压后运行同名 EXE；自包含 .NET 运行时。SSH 终端需要 WebView2 Runtime；个人账户 Azure CLI Runtime 按需下载。
- 退出旧版后启动新版，本地账户 / 设置 / 任务 / SSH 凭据保留；不需要清空本地数据。首次启动仍可使用 Demo 模式，登录服务需自行配置。
- 原有审批档位保留；缺少审批字段的新设置使用关闭档，强制影响确认不受影响。请求超时缺少或无效时归一化到 300 秒。
- 回退：退出新版，运行已归档旧版产物；旧版不会提供新页面和设置能力，不要删除或覆盖旧版本快照。
