# Changelog

本项目遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/)。
每个正式版本的**完整**变更记录见 `releases/vX.Y.Z/CHANGELOG.md`（含验证结果与已知问题）。

## v0.4.1 — 2026-09-14

修复正式版单文件 EXE 无法配置 Azure 登录服务的问题。

**主要修复**
- 「设置 → 账户 → 登录服务」可直接填写应用（客户端）ID；账户范围改为选择（多个组织 = `organizations` / 单个组织 + 目录（租户）ID）
- 配置保存到 `%LOCALAPPDATA%\CloudFlow\appsettings.json`，优先于程序目录配置；首次配置立即生效
- 未配置提示改为指向设置页，不再要求复制模板文件

**验证**：`dotnet build CloudFlow.sln -c Release -t:Rebuild` 0 警告 0 错误；481 项测试全部通过；单文件 EXE 无 `appsettings.json` 启动并显示配置入口。

**主要已知问题**
- 在设置页保存配置后完成登录的端到端验证未执行

完整清单见 [`releases/v0.4.1/CHANGELOG.md`](releases/v0.4.1/CHANGELOG.md)。

## v0.4.0 — 2026-09-14

资源组与所有资源支持批量删除；首页随窗口自适应宽度与高度。

**主要能力**
- 「资源组」「所有资源」列表支持勾选与全选，「删除所选（N）」合并为一次确认（须输入「删除 N 个资源组 / 项资源」），逐项执行并显示进度；每项仍是独立 Job 与审计记录，取消时作废本轮待审批任务
- 所有资源按依赖顺序删除（网卡 → 其它 → 虚拟网络 → 网络安全组 / 路由表）
- 首页不再限宽 1200，最大化时铺满；「最近操作 / 注意项」随窗口高度伸缩，底部不再留空
- 首页读取状态增加旋转图标；Scope「全部可访问订阅」改为「所有订阅」

**主要修复**
- 删除失败时该行不再从列表消失（按 Job 状态判断，只有成功才移除）

**验证**：`dotnet build CloudFlow.sln -c Release -t:Rebuild` 0 警告 0 错误；460 项测试全部通过；单文件 EXE 无 `appsettings.json` 启动验证通过。

**主要已知问题**
- 批量删除与单项删除在真实 Azure 上的端到端验证未执行

完整清单见 [`releases/v0.4.0/CHANGELOG.md`](releases/v0.4.0/CHANGELOG.md)。

## v0.3.0 — 2026-09-14

新增「资源」管理入口，创建虚拟机支持按需新建网络并接入真实 Azure 目录，完成一轮界面专业化重设计。

**主要能力**
- 侧栏「资源」分组：「所有资源」「资源组」两个列表，支持搜索；删除资源组 / 单个资源经 Operation Engine，不可绕过确认，删除资源组须输入名称
- 创建虚拟机：资源组 / 虚拟网络 / 子网不存在则新建、存在则复用（设计文档 v3.2 §87.2）
- 创建向导接入真实区域 / 规格 / 资源组目录，提示镜像与规格世代不匹配，显示预估月费
- 任务子步骤进度上报与顶栏「任务进行中」徽标；创建 / 删除对话框就地显示进度与失败原因
- 界面专业化重设计与全站文案规范化；统一确认对话框替换原生 `MessageBox`

**主要修复**
- 删除虚拟机时单件连带资源失败不再中断后续清理；已停止的虚拟机可直接解除分配
- 修复 Wpf.Ui 3.0.5 高码位图标乱码，并新增守护测试

**验证**：`dotnet build CloudFlow.sln -c Release -t:Rebuild` 0 警告 0 错误；459 项测试全部通过；单文件 EXE 无 `appsettings.json` 启动验证通过。

**主要已知问题**
- 删除资源组 / 单个资源的真实 Azure 端到端验证未在发布验证中执行
- 同时创建多台虚拟机时进度提示可能串台

完整清单见 [`releases/v0.3.0/CHANGELOG.md`](releases/v0.3.0/CHANGELOG.md)。

## v0.2.0 — 2026-09-13

创建 / 删除虚拟机的 P1 界面与执行链路正式交付，并移除成本洞察的模拟账单金额。

**主要能力**
- 两步「创建虚拟机」向导：已有资源组 / 子网、Ubuntu 或 Windows 镜像、常用规格、可选 Standard 静态公网 IP、SSH 公钥或密码认证
- 创建动作统一经过 Operation Engine；密码先写入 DPAPI 凭据库，待审批请求只保存凭据 Id
- 真实 ARM 创建链路按公网 IP → NIC → VM 顺序执行，创建前拒绝同名 VM / NIC / 公网 IP 覆盖
- 列表页创建入口替换原占位提示；创建或删除完成后自动刷新清单
- 删除虚拟机 UI（行菜单 + 连带资源勾选确认）随本版本发布
- 未登录时成本洞察显示空态并提示登录，不再展示模拟金额或模拟环比

**验证**：`dotnet build CloudFlow.sln -c Release -t:Rebuild` 0 警告 0 错误；完整测试结果见版本快照。

**主要已知问题**
- 批量 SSH 连接、批量主机指纹确认与创建 VM 尚未完成真实 Azure 端到端 UI 验证
- 快照入口仍是占位弹窗，后端已实现

完整清单见 [`releases/v0.2.0/CHANGELOG.md`](releases/v0.2.0/CHANGELOG.md)。

## v0.1.0 — 2026-09-13

首个正式发布。P1 阶段（VM 运维 + 多订阅）功能面完整。

**主要能力**
- 多订阅清单与跨订阅 VM 列表（Azure Resource Graph）；MSAL 设备码 + 嵌入式 Azure CLI 两条身份
- VM 运维全部经 Operation Engine（启停 / 重启 / 关机 / 解除分配 / 改规格 / 快照 / 网络规则）
- 应用级底部终端面板与多标签 SSH 会话（WebView2 + xterm.js）
- 全局 SSH 凭据库（DPAPI，元数据与密文分文件）；连接入口覆盖详情页、列表菜单与批量连接
- 主机指纹两段式校验：首次记录需确认、变化强警告、绝不静默接受
- **创建 / 删除虚拟机纳入 P1 范围**（设计文档 v3.1 §87；引擎侧完成，界面待实现）

**验证**：`dotnet build -c Release -t:Rebuild` 0 警告 0 错误；421 项测试全部通过

**主要已知问题**
- 批量连接与创建/删除虚拟机的界面尚未端到端验证（创建/删除的 UI 亦未实现）
- 快照入口仍是占位弹窗，后端已就绪

完整清单见 [`releases/v0.1.0/CHANGELOG.md`](releases/v0.1.0/CHANGELOG.md)。

## 版本与快照约定

- 正式发布使用 `MAJOR.MINOR.PATCH`，Tag 为 `vX.Y.Z`（不加产品名前缀）。
- 每次正式发布创建 `releases/vX.Y.Z/`：`source/`（源码快照）与 `CHANGELOG.md` **入库**；
  **二进制产物不入库**，作为 GitHub Release 的附件交付。
- 已发布的快照不可覆盖：发现 Bug 时发新版本，而不是修改旧快照。
